# 日本語

## 脆弱性の報告

脆弱性を見つけた場合は、公開のIssueではなく、GitHubの非公開の脆弱性報告で連絡してください。

https://github.com/myhomeisthinking-sketch/ha-switchbot_ir/security/advisories/new

再現手順と、影響を受けるバージョンを添えてください。確認でき次第、修正版を公開します。

## 対象

最新のリリースのみを対象とします。

# English

## Reporting a Vulnerability

If you discover a vulnerability, please report it through GitHub's private vulnerability reporting feature instead of creating a public issue.

https://github.com/myhomeisthinking-sketch/ha-switchbot_ir/security/advisories/new

Please include reproduction steps and the affected version. A fix will be released as soon as the issue is confirmed.

## Supported Versions

Only the latest release is supported.
